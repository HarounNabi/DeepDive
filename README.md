# Deepdive 4 | Team Één

## De Opdracht

Ons doel wordt om een leuke, interactieve Quiz te maken om een bezoeker bij de Bit Academy kennis te laten maken met onze opleiding.

In deze quiz leren hun wat ze allemaal kunnen verwachten van de opleiding, hoe wij werken in de opleiding. En een stukje leren!

## Ons Idee

Wij maken zoals vermeld in de opdrachtkenismaking een website met daarop een Quiz erop, bij de quiz zit: Een scoreboard en 4 kamers met verschillende puzzels. Zodra de laatste kamer is opgelost zal de eindscore te zien zijn, samen met hoeveel vragen je per kamer juist hebt beantwoord!

We gaan ook proberen een "Eindcode" toe te voegen, waarmee je de gehele escape room uit zou kunnen!

Vanaf de docenten kant zou het leuk zijn als de het gewonnen team, ook nog een leuke prijs na keuze krijgt van de Bit Academy!

## Het Eindproduct

Ons eindproduct is uiteindelijk iets anders geworden dan verwacht!

We hebben geprobeert toe te voegen dat je aan het einde van elke kamer een klein stukje codewoord zou krijgen. En hiermee uiteindelijk op de "Eindcode.php" kon ontsnappen uit de gehele, maar dit is uiteindelijk niet gelukt!

Verder hebben we onze doelen behaald en zijn we heel trots op het resultaat.

Om het product te runnen kun je de volgende stappen volgen:


1. Clone de repo: (git clone https://github.com/NP-BIT-Dev/deep-dive-2526-p4-team-1-1.git)

2. Open XAMPP en start Apache en MySQL op.

3. Open de folder genaamd "db" en run "queries.sql" in je MySQL localhost pagina, hiermee clone je onze database naar jouw computer.

4. Open Apache in de folder waar jij de repo hebt gecloned en navigeer naar de public folder.

5. Maak de quiz!
